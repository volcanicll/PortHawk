macOS · menu bar · native SwiftUI

Which app owns which port,
which project runs which port.

PortHawk keeps a ledger of every TCP listening port on your Mac: who is listening, which project it belongs to, and whether the LAN can see it. Refreshed every 3 seconds — a native SwiftUI binary of about 1 MB, no Electron, no background daemons.

Six strokes of the pen

01Project ownership

Reads each process's working directory to infer its project. Switch between "by project" and "by port" views — dev servers stop being anonymous.

02Detail inspector

Open any row for a full page: complete command line, executable path, user, threads, memory and live CPU%.

03Ink cancellation

Hover for "End"; a two-step confirm prevents accidents. A killed row gets struck through with a vermilion line, like ink cancelling a ledger entry.

04Favorites & alerts

Star the ports you care about; idle favorites show a faint placeholder row, and a stranger taking the port lights a dot in the menu bar.

05Exposure

Ports bound to 0.0.0.0 get an ochre "LAN" badge; an "exposed only" chip filters your attack surface in one click.

06Light & native

A native SwiftUI menu bar app of about 1 MB. Scans at launch; on failure it keeps the last snapshot and says so — it never pretends there are no ports.

Three steps in

Recommended — one terminal command downloads the latest build into /Applications and sidesteps Gatekeeper entirely:

curl -fsSL https://volcanicll.github.io/PortHawk/install.sh | bash
  1. 1
    or manually download the DMG and drag PortHawk.app into Applications
  2. 2
    if macOS says the app is "damaged" or from an "unidentified developer": the binary is ad-hoc signed (not notarized). Run xattr -cr /Applications/PortHawk.app and open again
  3. 3
    a book icon and a port count appear in your menu bar — click and go

Prefer building from source? git clone then ./build.sh — Command Line Tools is all you need.
